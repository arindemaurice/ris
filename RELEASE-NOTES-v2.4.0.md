# RIS v2.4.0 Operations Upgrade

## Included

- Dedicated `/super-admin` route and restricted sign-in screen.
- Platform administrator username sign-in using `RIS_BOOTSTRAP_ADMIN_NAME` (default: Maurice Arinde) or bootstrap email.
- Global customer operations across ISP tenants: filter by ISP, search, create, suspend, reactivate and archive/restore as pending.
- ISP customer operations: add with optional package, search, edit, suspend/reactivate, archive and restore.
- Soft archival preserves financial history. Network account state and FreeRADIUS SQL authorization rows are updated when SQL integration is enabled.
- Audit entries record tenant-level and platform-level customer changes.
- Updated setup, README, audit roadmap and trial test plan.

## Verification

- `python -m py_compile backend/app.py backend/setup.py backend/worker.py`
- `node --check frontend/assets/app.js`
- `python -m pytest -q`: 26 passed.

## Important limitations

This release is not certified for production ISP operation. Public captive-portal live guest checkout, direct RouterOS subscriber provisioning, RADIUS accounting ingestion, CoA/Disconnect for already-connected sessions, complete PPPoE lifecycle, commission reconciliation, full refunds and production security review remain incomplete. Live payment and network integrations require provider credentials and safe end-to-end tests.

The platform bootstrap password is randomly generated by `backend/setup.py` and kept in the private `backend/.env`; it is not hard-coded in the project. Change it after first login and never commit `.env`.
